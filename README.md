# موقع AXIS - معرض علي اكرم للالكترونيات

موقع ألعاب PS4 للمحل. الزبون يختار الألعاب ويرسل الطلب على واتساب.

## التعديل
- **الألعاب ومعلومات المحل:** كلها بملف `games.js`. افتحه على GitHub واضغط أيقونة القلم ✏️، عدّل، وبعدين اضغط **Commit changes**. الموقع يتحدث خلال دقيقة أو دقيقتين.
- **صورة الغلاف:** ارفعها لمجلد `covers` (Add file ← Upload files)، وبعدين اكتب مسارها بحقل `cover` للعبة، مثلاً `covers/g99.jpg`.
- **حذف لعبة:** احذف القوس `{ ... }` الخاص بيها من `games.js` ويا الفاصلة اللي بعده.
- **روابط تيك توك وفيسبوك:** بحقل `tiktok` و `facebook` بأول الملف.
